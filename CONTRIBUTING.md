# Contributing

The project is currently in specification. Discuss scope changes before implementing major features.

Write UI, educational content, and documentation in English. Distinguish upstream Kubernetes behavior from Linux and plugin-specific behavior. Cite primary sources for the supported version and identify educational simplifications.

When adding a mechanism, document prerequisites, participating components, state changes, failure cases, supported profiles, and verification evidence. Update coverage and the changelog. Installation and automated validation commands will be added with the implementation.

Inventory external assets and dependencies, their versions, origin, license, and local replacement strategy. Preserve required upstream notices when reusing code. Never include credentials.
